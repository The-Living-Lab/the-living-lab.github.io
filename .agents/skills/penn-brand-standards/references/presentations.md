# Penn Presentations (PowerPoint and Slides)

Source: University Communications' official *PowerPoint Template 2027*. Download the template: https://upenn.box.com/s/sansx8571lhc5djf2091f6clea64uu5p. Questions: University Communications, ucomms-web@upenn.edu.

Read this whenever a task involves a slide deck, presentation, or slide graphic carrying the Penn brand, in PowerPoint, Keynote, Google Slides, or HTML slides. These rules add to the brand standards in `SKILL.md`; they don't replace them.

## Start from the official template

The template carries the approved backgrounds, logo placements, fonts, and colors. Build from it rather than recreating the design.

- **If you have the template and can work with .pptx files** (for example with python-pptx), open the template and add slides from its layouts. Don't redraw its design on blank slides.
- **If the user doesn't have the template**, point them to the link above first. If they still want a draft without it, follow the colors, fonts, and patterns below, and tell them it's a draft to move into the official template, not a finished Penn deck.
- **In another tool** (Google Slides, Keynote, HTML), the same applies: follow the rules below exactly, and say the deck isn't built on the official template.
- The template's own tips: edit it in the desktop PowerPoint app, not PowerPoint online, because the brand fonts don't display properly online. Duplicate an existing slide to get fully editable design elements; insert a new slide from a layout to keep the background elements locked.

## Colors

| Color | Hex | Use in slides |
|---|---|---|
| Penn Blue | `#011F5B` | Dominant: full-slide and panel backgrounds, titles and body text on white |
| Presentation red | `#E0201D` | Accent: the emphasized words in titles, subheads, numbers, icon circles, photo frames |
| White | `#FFFFFF` | Backgrounds; titles and body text on Penn Blue |
| Light gray | `#F2F2F2` | Backgrounds, table banding |
| Green | `#6BAA75` | Third chart series only |

- **The presentation red is not Penn Red.** University Communications chose this brighter red (the same red Penn Today uses) because Penn Red `#990000` gets lost on Penn Blue. Use `#E0201D` in presentations only. Websites must not use it, and neither should print, stationery, or merchandise: everywhere outside slide decks, Penn Red `#990000` is the brand red.
- **Red on Penn Blue is for large text only** (titles, subheads, large numbers). The contrast ratio is about 3.3:1, which passes accessibility guidelines only for large or bold text. Body text on Penn Blue is white.
- Charts use Penn Blue first, then the presentation red, then green.
- Don't add other colors, including the web accents (gold, light blue). The template's theme file lists a few more accent colors; they aren't part of the design, so don't use them.

## Typography

| Use | Typeface | Size in the template |
|---|---|---|
| Slide titles | **ITC Stone Serif SemiBold** (Stone Serif ITC Pro) | 36 pt |
| Subheads, numbered markers ("01", "02"), metrics | ITC Stone Serif SemiBold, in the presentation red | 24 pt |
| Body text | **Noto Sans** (Noto Sans Medium for emphasis) | 16–20 pt |

- These are Penn Today's fonts. Noto Sans is free from Google Fonts. ITC Stone Serif is licensed and is embedded in the template file.
- If ITC Stone Serif isn't available (Google Slides, HTML slides), use EB Garamond SemiBold as the stand-in serif.
- Don't use any other fonts in a Penn deck, including the web fonts (Roboto, and EB Garamond as body text).

## Design patterns

- **Two-tone titles**: the first part of the title in Penn Blue (white on blue slides), the key words in the presentation red. For example: "Click to Edit **Slide Header**".
- **Shield watermark**: blue slides and panels show the **complete University shield**, large and in a slightly lighter tint of Penn Blue, as a background texture. Use the watermark that's built into the template; don't recolor or recreate the shield yourself to make one, and leave it out when you're working without the template. Never pull apart the elements of the shield for decoration: no chevron on its own, no roundels on their own, no patterns built from shield pieces.
- **Logo placement**: the full reversed Penn logo (shield, Penn Mark, and logotype) on the title slide. The shield, from the template, in the bottom-right corner of every content slide (all layouts except Blank). Slide numbers in gray (`#797979`) at the bottom left.
- **Bullets**: red "»" markers, with square sub-bullets.
- **Numbered points**: large red serif numbers ("01", "02") beside a red subhead and body text.
- **Photos**: a red offset block behind the photo, or a red vertical rule beside it on the title slide.
- **Icons**: simple white line icons in red circles.
- **Tables**: Penn Blue header row, alternating light gray rows.
- **Metrics**: Penn Blue boxes with large red numbers and white captions.
- Layout is 16:9 widescreen.

## Layouts in the template

Pick the layout that matches the content:

| Layout | Use for |
|---|---|
| Title | Opening slide: title, presenter, date, photo |
| Agenda | Up to three grouped lists of agenda items |
| Section Title | Dividers between sections |
| Presenters | Up to three people with photos and short bios |
| Quote | A single quotation with attribution |
| Text and Photo | Text with one photo, optionally with numbered points |
| Text and Chart | A chart with up to three short explanations |
| Text and Table | A table with up to three short explanations |
| 1-Column Text White / 1-Column Text Blue | Bulleted text slides |
| 2-Column Text Option 1–4 | Side-by-side text, icon lists, numbered lists |
| Boxes - Text | Up to six short points in boxes |
| Boxes - Metrics | Up to six key numbers |
| Blank Logo | Free-form content with the shield and slide number |
| Blank | Full-bleed content |

## Checklist

- [ ] Built from the official template (or labeled as a draft not built on it)
- [ ] Penn Blue dominant; presentation red `#E0201D` used for accents only, and only in the deck
- [ ] Red text on Penn Blue only at title, subhead, or number size; body text on blue is white
- [ ] Titles and subheads in ITC Stone Serif SemiBold; body in Noto Sans
- [ ] Full reversed logo on the title slide; shield bottom-right on other slides; logos are official files, unmodified
- [ ] Shield watermarks use the complete shield, never pieces of it
